# Formatting Data From PharmacoGx

Converts each type of raw omics data into the same units and formatting as CSA benchmark data. Assumes PharmacoDB datasets have already been downloaded and stored as CSVs using the scripts from /data_retrieval

## 📂 Repository Structure
1. **gen_gene_expr.py** 
- Loops through a folder of summarized rnaseq data (generated by /data_retrieval/summarize_gene_expr) and converts data to CSA structure. Original columns in RNAseq files are Ensemble Gene IDs with version numbers (.XX), this script strips version numbers and averages replicates to get one value per sample per gene. A gene info file is used to map ensemble IDs to entrez IDs and gene symbols to build gene metadata rows, dropping unmatched genes to ensure consistency. Data is initially in log2(x+.001) [See https://www.orcestra.ca/pset/5ef3659e785cc307d861e79c] so it is transformed into log2(x+1) for consistency with CSA data.
2. **gene_info.csv**
- A file downloaded from NCBI (https://ftp.ncbi.nih.gov/gene/DATA/gene_info.gz) containing mappings between ensemble ID, entrez ID, and gene symbol.

See https://pharmacodb.ca/datasets and https://www.orcestra.ca/pset/5ef3659e785cc307d861e79c for more information on source datasets
